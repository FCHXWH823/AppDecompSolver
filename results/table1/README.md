# Table 1 reproduction results

`results.json` is generated by `experiments/run_table1.py`. It stores the
paper values, exact commands, raw output, MED, solver-reported runtime, wall
runtime, and timeout/failure state for every run.

The default run covers separate and joint modes of the two retained Ising
presets: `paper` and `paper-plus`. DALTA/Gurobi methods are opt-in because the
paper's joint ILP reaches its 3600-second limit and the released separate
formulation behaves very differently under Gurobi 12 than under the paper's
Gurobi 9.1.

`dalta-separate-cos.json` records a bounded but complete 126-partition
separate-ILP run. It is kept separate from `results.json` so the normal suite
can be regenerated without spending several extra minutes in Gurobi.

`paper-results.json` contains the `paper` preset. It
uses the same matrix orientation and core, but only one seeded bSB trajectory,
one fixed field schedule per mode, the paper's dynamic stop, and the paper's
exact conditional column-type feedback. It intentionally disables the
portfolio, final-LUT MED selection, and ER slack. Its average MED is 7.420 in
separate mode and 2.514 in joint mode, versus 7.83 and 2.51 in the paper.

`FIELD_SWEEP.md` records the independent-field calibration experiment used for
the `paper` preset.

`paper-plus-results.json` contains the minimal field-portfolio extension.
It uses one seed, two complete trajectories for separate and three for joint,
with no ER slack or hybrid refinement. Its average MED is 6.883 in separate
mode and 2.386 in joint mode. Five of six separate results and all six joint
results are no worse than the corresponding Proposed values.
